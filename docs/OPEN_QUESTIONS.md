# 남은 결정과 근거

기준: 2026-10-07 회의록과 같은 날 저장소 확인. 아래 내용에 의존하는 구현만 보류한다. 확정된 영역의 작업은 계속한다.

## 10/7에 확인된 내용

- DOCKER 입력은 Dockerfile을 뜻한다. Docker 이미지·실행 중 컨테이너 입력으로 확대하지 않는다.
- 제품 LLM은 우선 Terraform 변수값까지만 바꾼다. HCL 전체 변경은 토요일까지 가능성을 보는 확장 목표다.
- 기술 스택 표에는 HTML·JavaScript, Python·FastAPI, MySQL, AWS가 기재됐다.
- `OLLAMA_API_KEY` secret 이름이 공유됐다. 모델 결정 칸에는 모델을 정한 뒤 적으라고 되어 있다.
- DB 마이그레이션 안건의 결정 칸은 비어 있다. 안건의 체크 표시만으로 확정으로 처리하지 않았다.
- 샘플 백엔드 계약의 참조 위치는 샘플 프런트 README다.

## 먼저 정해야 하는 항목

| 항목 | 필요한 결정 | 영향을 받는 작업 |
|---|---|---|
| LLM | 모델명·버전, endpoint·SDK, 로컬 키 주입, 한도·결제 담당 | 실제 LLM 연동 |
| DB 테이블 | 앱 초기화인지 마이그레이션 명령인지, 실행 주체·재실행·실패 처리 | 샘플 백엔드·실제 배포 |
| 배포 실패 | 첫 배포 실패, 한 환경만 성공, 롤백 실패, 자동 복구 범위 | 배포 상태 전환·데모 |
| 샘플 실행 계약 | 컨테이너 수, 포트, 헬스 경로, DATABASE_URL 형식, 정적 파일 제공 방식 | 샘플 백엔드·Terraform |
| 입력 UI | ZIP 내부 Dockerfile만 지원하는지, Dockerfile 별도 업로드도 받는지 | 업로드·스캔 |

| 공통 API | 배포·상태·롤백 요청/응답과 오류·상태 스키마 | 프런트·백엔드·어댑터 통합 |
| 공유 인프라 | ALB listener·포트·보안 그룹·state 소유권, SSM/Secrets Manager 선택 | AWS 모듈 |
| 비용 | foundation 고정 비용과 앱 추가 비용의 포함 범위, 리전·가격 기준 | 비용 표시·예산 판정 |
| CI/CD | 앱별 필수 검사 명령, main 합친 뒤 산출물·실제 배포 범위 | 저장소 자동화 |

## 이후 확인할 항목

- Python 세부 버전과 패키지 관리자. 저장소에 manifest·lockfile이 생기면 실제 설정을 우선 확인한다.
- HCL 전체 변경의 도입 여부와 검증·승인 기준. 현재 기본 범위는 변수값이다.
- 모듈 수와 추천 방식. 모듈이 하나면 AI가 여러 모듈 중 고른다고 설명하지 않는다.
- 트래픽 변경안을 승인 없이 적용할지에 관한 과거 회의록 충돌. 확정 전에는 제안까지만 한다.
- 로컬 앱의 외부 접근 판정, git 입력 인정, 개인 코드 재사용, API 비용 지원 여부에 대한 운영진 답변.
- 제출·중간보고·발표 담당. 10/7 확인 목록에는 있으나 읽은 본문에 결정이 없다.
- 진동현의 역할은 팀장 초안 기준이다. 10/6 역할표의 빈 내용을 새 합의로 간주하지 않았다.
